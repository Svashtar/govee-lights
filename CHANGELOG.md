# Changelog

All notable changes to Govee Lights are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow `version-name` in `metadata.json`.

## [Unreleased]

### Added
- First public version in development: LAN + cloud control, Quick Settings tiles, top-bar menu, multi-light presets.
- About page with release notes, debug info for bug reports and settings backup.
- Applying a preset keeps the menu open and marks the active preset with a checkmark.
- Scene, DIY scene, snapshot and music mode lists are sorted alphabetically.
- Long scene, DIY scene, snapshot and music mode lists scroll inside the menu and have a search field.
